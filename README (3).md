# Agent Portrait Prompt Builder

Single-file tool that builds AI image prompts for professional real estate portraits of your team.

- 36 styles (board and banner poses, studio, model house, on-site, lifestyle, editorial, print)
- Leader (royal blue polo) and teammate (red top) presets
- Half body or full body framing
- Separate pants/shorts and shoes fields for the leader and the team
- Optional sign or banner text, footer-bar spacing, aspect ratios

## Use it
Open `index.html` in any browser. No install, no server, no dependencies.

## Host it free with GitHub Pages
1. Repo Settings, then Pages
2. Source: Deploy from a branch, Branch: `main`, Folder: `/ (root)`
3. Save. Your link will be `https://YOUR-USERNAME.github.io/REPO-NAME/`
